# Pizza Sales Analytics

This component analyses one year of fictitious pizza-restaurant sales data containing **48,360 rows**. The project uses **Microsoft SQL Server and Power BI**.

## Analysis performed
The SQL analysis covers:
- Total revenue
- Average order value
- Total pizzas sold
- Total orders
- Average pizzas per order
- Daily and monthly order trends
- Sales mix by pizza category and size
- Top and bottom pizzas by revenue, quantity and order count

The project also documents data preparation activities such as data-type conversion, missing-value handling, consistency checks and derived date fields such as day name/number and month name/number.

## Reported findings
The original project presentation reports that **Thai Chicken Pizza** was the top-selling pizza and **Brie Carre Pizza** was identified as a weaker performer. It also reports stronger demand for the **Classic** category / large size and higher order activity on **Fridays** and in **July**.

## Business recommendations documented in the project
The presentation links the analysis to menu optimisation, inventory management, staffing, marketing campaigns and opportunities to improve lower-performing products and cross-sell sides/beverages.
